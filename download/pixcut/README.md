# پیکس‌کات استودیو — PixCut Studio

برش هوشمند تصویر، حذف پس‌زمینه، استخراج فریم شفاف از ویدیو و GIF با کلید رنگی، فلیپ‌بوک و اسپرایت‌شیت — **همه‌چیز کاملاً داخل مرورگر شما** بدون ارسال هیچ فایلی به سرور.

**استفاده آنلاین:** https://sahandmarami.github.io/pixcut-studio/

---

## امکانات

### ۱. برش و پس‌زمینه
- تشخیص خودکار اشیاء با موتور بینایی ماشین محلی (تخمین رنگ پس‌زمینه + Flood-Fill + لیبلینگ اجزای همبند)
- بوم برش تعاملی: رسم کادر جدید با درگ، جابجایی، ۸ دستگیره تغییر اندازه، زوم و پن
- حذف پس‌زمینه با Flood-Fill لبه‌محور + سد گرادیان Sobel، حذف حفره‌های محصور (سقف ۸٪ مساحت)
- تنظیمات: حساسیت رنگ، نرمی لبه (Feather)، پالایش لبه (Defringe)، رفع سرریز رنگ (Despill)
- ویرایشگر ماسک: پاک‌کن، بازیابی، چوب جادویی، قطره‌چکان + برگرداندن/ازنو
- دانلود مستقیم هر برش + ZIP همه با نام‌گذاری خودکار `cut_001.webp`

### ۲. فریم‌های شفاف
- پشتیبانی از MP4 / WebM / MOV و GIF (دیکدر کامل GIF با پشتیبانی Interlace و Disposal)
- انتخاب تعداد فریم: **۸ / ۱۲ / ۱۶** (و «همه فریم‌ها» برای GIF)
- نمونه‌برداری یکنواخت زمانی غیرمسدودکننده + نوار پیشرفت درصدی
- کلید رنگی زنده: سبز/آبی/سفید/مشکی/سفارشی، قطره‌چکان، حساسیت، نرمی لبه، رفع سرریز
- سه تست یک‌کلیکی: اسپرایت‌شیت (Canvas)، ویدیوی شفاف (MediaRecorder)، GIF شفاف (انکدر داخلی)

### ۳. انیمیشن و خروجی
- فلیپ‌بوک با FPS از ۱ تا ۳۰، پخش/توقف، حرکت فریم‌به‌فریم، پس‌زمینه‌های شطرنجی/سفید/مشکی/سبز/سفارشی
- سازنده اسپرایت‌شیت با تنظیم ستون‌ها، فاصله و مقیاس + پیش‌نمایش زنده
- متادیتای سازگار: **Unity (فرمت TexturePacker JSON)** و **Godot (فایل .tres SpriteFrames)**
- خروجی WebP شفاف باکیفیت یا PNG، دانلود تکی / گروهی با نام‌گذاری خودکار / ZIP

## اجرا

هیچ وابستگی‌ای لازم نیست — فایل‌ها را روی هر وب‌سرور استاتیک بگذارید:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080 را باز کنید
```

## فناوری

جاوااسکریپت خالص (ES Modules) + Canvas API — بدون هیچ کتابخانه خارجی:
- کدک GIF (دیکدر + انکدر LZW با پالت Median-Cut) نوشته‌شده از صفر
- نویسنده ZIP (روش Store + CRC32) از صفر
- پردازش پیکسلی با Typed Arrays برای کارایی
