# اسپرایت‌فورج — SpriteForge

استودیوی کامل برش شیت تصاویر، حذف پس‌زمینه و استخراج فریم از ویدیو/گیف — کاملاً داخل مرورگر، بدون آپلود هیچ فایلی به سرور.

**لینک نسخه‌ی آنلاین:** https://sahandmarami.github.io/spriteforge/

## امکانات

### ۱) برش‌زن شیت تصویر
- **تشخیص دوگانه:** موتور Vision AI سروری + موتور بینایی ماشین کاملاً آفلاین (اسکن پیکسلی، رنگ غالب، مؤلفه‌های همبند CCL) — روی هاست استاتیک به‌صورت خودکار به موتور محلی برمی‌گردد
- **بوم کادر تعاملی:** کشیدن کادر جدید، جابجایی، ۸ دستگیره تغییر اندازه، زوم/پن، حذف با Delete
- **موتور حذف پس‌زمینه:** فیلودفیل از لبه‌ها با سد گرادیان Sobel، حذف حفره‌های محصور با سقف مساحت، Feather / Defringe / Despill
- **ویرایشگر ماسک:** پاک‌کن، بازیابی، چوب‌جادویی + قطره‌چکان، Undo/Redo
- **دانلود:** هر برش به‌تنهایی (WebP شفاف) یا همه با هم به‌صورت ZIP با نام‌گذاری خودکار

### ۲) استودیو ویدیو و گیف
- پشتیبانی MP4 / WebM / MOV و گیف (دیکود کامل فریم‌ها با gifuct-js)
- انتخاب دقیق تعداد فریم: **۸ / ۱۲ / ۱۶** (گیف: همه فریم‌های اصلی)
- نمونه‌برداری زمانی یکنواخت غیرمسدودکننده با نوار پیشرفت
- **کروماکی زنده:** پرده سبز/آبی/سفارشی + قطره‌چکان، حساسیت، نرمی لبه، Despill
- سه تست یک‌کلیکی: اسپرایت‌شیت، ویدیوی پرده سبز (MediaRecorder)، گیف شفاف (gifenc)

### ۳) انیماتور و خروجی
- فلپ‌بوک ۱ تا ۳۰ FPS با پیمایش فریم و پس‌زمینه انتخابی
- سازنده اسپرایت‌شیت (ستون‌ها/فاصله) + متادیتای **Unity / Godot** (JSON)
- خروجی WebP شفاف با کیفیت دلخواه، نام‌گذاری `prefix_001` و **ZIP گروهی با JSZip**

## اجرا روی موبایل و دسکتاپ
طراحی موبایل‌اول (RTL، فونت وزیرمتن)، اهداف لمسی بزرگ، نوار عملیات شناور چسبان و **تم روشن/تاریک** با حفظ هویت رنگی (Slate + بنفش فلزی + فیروزه‌ای نئونی).

## اجرای محلی

```bash
bun install
bun run dev          # حالت توسعه (پورت ۳۰۰۰) با API تشخیص AI
bun run build:static # خروجی استاتیک GitHub Pages در .next-export
```

## نشر روی GitHub Pages
پوشش `main` → اکشن `.github/workflows/deploy.yml` به‌صورت خودکار بیلد استاتیک (`STATIC_EXPORT=1`، `basePath=/spriteforge`) را اجرا و در Pages منتشر می‌کند. مسیرهای `/api/*` فقط در حالت توسعه در دسترس‌اند و در هاست استاتیک، تشخیص AI خودکار به موتور آفلاین مرورگر سوئیچ می‌شود.

## فناوری‌ها
Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zustand · gifuct-js · gifenc · JSZip · lucide-react — همه پردازش‌ها سمت کلاینت و هیچ فایلی به سرور ارسال نمی‌شود.
